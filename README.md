# Movie Explorer

A simple React Movie Explorer built with React, React Router, Tailwind CSS, and the TVMaze API.

## Features

- Home page with navbar, hero banner, CTA, and footer
- Browse shows from the TVMaze `/shows` endpoint
- Search shows by title with the `/search/shows?q=` endpoint
- Responsive movie card grid
- Movie poster, title, release year, and rating
- Details modal with poster, summary, rating, release date, and genres
- Loading, error, and empty-result states
- Responsive layout for mobile and desktop

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
